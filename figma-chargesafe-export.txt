## DASHBOARD SCREENS
====================================================================

### 1. Home Screen (node 134:619)
Main user dashboard — bottom nav: Home (active), Map, Hub, Profile
- Top Status Bar: 9:41, Cellular, Wifi, Battery
- HomeIndicator (bottom bar indicator)
- Assigned Hub header: 3D Avatar with green "safe" status dot, "ASSIGNED HUB" label, location pin + "Haining Road, Kingston 5, Jamaica"
- Alert banner (amber): warning icon + "Active weather event — Kingston, Jamaica" / "Stay connected with your community hub"
- "CHECK IN NOW" section: Two large buttons side-by-side
  - "I Am Safe" (green/Safe fill, white text, checkmark icon, border-radius 69px)
  - "Need Help" (red/Urgent fill, white text, SOS icon, border-radius 64px)
- Map card (white, rounded 12px): Map Image (rectangle), location pin + "2 Hazards Near You", arrow icon, hazard map marker SVGs with shadow effects
- Hub Resources card (white, rounded 12px):
  - Header: "Hub Resources" + "OPEN" badge (green/Safe fill)
  - Power row: battery icon, "Power" label, "85% Power Capacity" value
  - Satellite Internet row: wifi icon, "Satellite Intenet" label, "Active" value (green)
  - "Book Charging Slot" button (dashed border, blue text)
- "Report a Hazard" link text
- Hazard categories grid (2 rows):
  - Row 1: Flooding (water icon), Blocked Road (road icon), Fallen Tree (tree icon)
  - Row 2: Medical (cross icon), Fallen Utility Pole (pole icon), Fire (flame icon)
    Each: white card with shadow, image + label
- "Additional Hazards" card (white, rounded 12px): Collapsed Building, Power Line Down, Landslide, Other (each with circle-outline icon)
- Bottom navigation bar (dark pill shape): focuses/Home (icon+label active), Map, Hub, Profile icons
